# 有效接线

CURRENT_STATE.md优先。调整先断电；不要让仍接3V3/GND的临时电机输入同时连ESP输出。用户已确认早期临时线撤掉并恢复GPIO。

## 语音板

| 模块丝印 | ESP引脚 / 连接 |
|---|---|
| INMP441 WS | G4 |
| INMP441 SCK | G5 |
| INMP441 SD | G6（麦克风输出→ESP输入） |
| INMP441 VDD / GND | 3V3 / GND |
| INMP441 L/R | GND（左声道） |
| 功放 LRC | G16 |
| 功放 BCLK | G15 |
| 功放 DIN | G7 |
| 功放 GAIN | 悬空 |
| 功放 SD | 3V3（使能；不同于麦克风SD数据线） |
| 功放 GND / VIN | GND / 5V，仅原模块支持5V时 |
| 扬声器 | 功放SPK+ / SPK-；扬声器规格未确认 |

保留用户实测成功的5cm麦克风线。语音板NoDisplay，无OLED接线要求。

## 两板串口

| 来源 | 目的 |
|---|---|
| 语音G13 TX | 电机G14 RX |
| 电机G13 TX | 语音G14 RX |
| 语音GND | 电机GND/H桥控制参考地 |

UART1 115200 8N1，3.3V逻辑，不接RS232电平。

## 电机板

| 路 | H桥输入 | GPIO |
|---|---|---|
| 左履带 | AIN1/AIN2 | G15/G16 |
| 右履带 | BIN1/BIN2 | G4/G5 |
| 躯干 | CIN1/CIN2 | G6/G7 |

这是电机板持久映射，不是语音板引脚表。原板已有NVS，不应重复改映射。新空板才用 `PINS 15 16 4 5 6 7` 后 `REBOOT`。H桥主电源、额定参数及使能端实物细节未确认，不能据此补画完整供电原理图。
