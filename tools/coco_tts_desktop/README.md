# Coco 电脑台词生成器

Windows 桌面窗口：输入台词、生成、试听和打开输出目录。默认使用本项目自己的小智设备和已知客户端UUID；可以在界面修改为自己的已绑定设备。

## 使用

本次部署的电脑直接双击桌面“Coco台词生成器”快捷方式。输入一段台词（1～300字），设文件名，点击“生成语音”。生成期间让同一小智设备暂时待机，避免同时对话争用服务。

默认输出在桌面“Coco台词”：

- `.ogg`：单声道 Ogg Opus，供 Coco 预置播放使用。
- `.wav`：24kHz、16bit、单声道，供电脑试听/剪辑。
- `.json`：请求文字、服务器返回文字、生成时间和音频参数，不含token。

再次生成用新文件名，已有文件不覆盖。新音频不会自动替换固件或刷入机器人；加入预置表后仍须重建资源和固件。音色取生成时小智服务的当前设置，缓存不会自动变化。

## 实际工作方式

这是项目原有“当前音色生成”的桌面封装：Windows Huihui先合成“请只说这句话”的请求音频，发送给自己的已绑定小智服务，再接收回复文字和音频。它不是一个独立的直接TTS模型，也不使用Windows音色作为最终结果。需要网络和正常的设备服务/绑定。

服务器可能不按要求复述；无论是否逐字一致，只要收到完整可解码音频就保存。JSON同时记录请求文字、实际回答和text_matches（忽略标点/空白），用于核对，不阻止保存。没有保证声学上每个字读音正确，生成后请试听；长台词建议拆短。客户端UUID应使用自己设备启动日志中的值，服务变更或失效时可能需要调整。

服务令牌只在内存中。台词会发送给自己的小智服务；临时请求音频在完成/失败/取消后清理。界面仅把MAC、UUID、输出目录保存在当前用户LocalAppData/CocoTTS/settings.json，不保存台词或令牌。输出音频和台词记录仅存用户所选目录，不自动纳入Git。

## 换电脑

需要Windows、Python 3.11或更高版本（含Tkinter）、Microsoft Huihui Desktop中文语音，以及网络。双击`install.cmd`安装依赖，再双击`start.cmd`。源码依赖与原工具一致，安装在本目录`.venv`；首次安装需要联网。此便携源码包不含Python运行时。

也可命令行：

```powershell
python engine.py "我来自烟台理工学院。" --output C:/CocoLines --name line_01
```

界面“取消”会尽快关闭会话；连接阶段需等当前网络操作超时，最长约35秒。取消后已发到服务的请求无法撤回；本地不保存未完成音频。本工具不控制电机、不访问串口。
